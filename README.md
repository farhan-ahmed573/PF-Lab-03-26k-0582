Lab Title: Introduction to GitHub and C Programming Language

 Introduction

This lab introduces the basic concepts of GitHub and C programming. It covers GitHub repositories, branches, commits, pull requests, Markdown documentation, C data types, input/output functions, format specifiers, escape sequences, and precision formatting.

 Objectives

1. To create and manage a GitHub repository.
2. To learn how to create branches, commits, and pull requests.
3. To understand basic C data types and format specifiers.
4. To practice C input/output functions.
5. To understand escape sequences and precision formatting.

 C Topics Covered

* Data Types
* Input/Output Functions
* Format Specifiers
* Escape Sequences
* Precision
* Character Input and Output
* String Input
